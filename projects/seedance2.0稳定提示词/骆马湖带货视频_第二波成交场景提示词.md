# 骆马湖瓶装水 Seedance2.0 第二波成交场景提示词

目标：在第一波稳定人物和产品的基础上，进一步做“适合带货的场景”。这一版重点不是单纯生成好看的画面，而是让画面、产品、口播台词、字幕卖点形成一致的购买理由。

使用方式：
1. 用骆马湖瓶装水产品图作为参考图，锁定透明方形瓶身、浅蓝瓶盖、浅蓝竖向标签。
2. Seedance2.0 里使用下面的“视频画面提示词”生成 5-8 秒画面。
3. 口播台词和屏幕字幕建议后期添加，不建议让模型直接生成文字。
4. 每个场景都围绕一个购买动机，不要一条视频塞太多卖点。

重要原则：
- 人：中年亚洲男性，真实、亲和、可信，像本地生活带货主播或门店老板。
- 货：骆马湖饮用天然水，清澈、干净、浅蓝标签、便携 500ml。
- 场：办公室、便利店、家庭餐桌、通勤车内、运动后、户外湖边、小店柜台等真实消费场景。
- 话术：短、具体、有场景，不夸大功效，不说医疗健康承诺。

固定人物设定：
中年亚洲男性，约 38-45 岁，短黑发，轻微圆脸，戴黑色细框眼镜，普通真实长相，亲和可信，不像明星，不夸张表演。身材中等，穿浅米色休闲卫衣、浅色针织上衣或日常休闲外套。动作克制，眼神看向镜头，手部真实自然。

固定产品设定：
一瓶骆马湖 LUOMA LAKE 饮用天然水，500ml，透明方形塑料瓶，浅蓝色瓶盖，浅蓝色竖向标签，标签主色为清爽湖蓝色，瓶身清澈透明，有真实折射、高光和轻微冷凝水。允许标签文字略微模糊，但瓶型、瓶盖颜色、标签主色和天然水气质必须保持。

通用负面约束：
不要蓝色背景布，不要广告棚大片感，不要改变瓶型，不要改变瓶盖颜色，不要改变标签主色，不要生成其他饮料，不要出现多余品牌，不要多人抢镜，不要手指畸形，不要夸张水花，不要医疗功效暗示，不要让画面出现大量错误文字。

# 成片结构建议

5 秒版本：
1. 0-1 秒：场景建立，人物和产品同框。
2. 1-3 秒：人物拿起产品，标签朝向镜头。
3. 3-5 秒：递近产品或轻喝一口，字幕给出核心卖点。

8 秒版本：
1. 0-2 秒：场景和购买理由。
2. 2-4 秒：产品特写，瓶型、标签、瓶盖清楚。
3. 4-6 秒：人物口播推荐，动作自然。
4. 6-8 秒：成交收口，字幕提示“家里常备 / 办公室常备 / 整箱囤水”。

最稳的后期字幕格式：
- 第一行：场景卖点，如“办公室常备水”
- 第二行：产品理由，如“500ml 随手补水”
- 第三行：成交提示，如“家里/车里/办公室都能放”

不要把价格、品牌大字、复杂促销信息交给视频模型生成，全部后期加。
